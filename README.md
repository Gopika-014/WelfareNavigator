
# Welfare Navigator

## Overview

Welfare Navigator is an AI-powered platform that helps citizens discover and access government welfare schemes through personalized recommendations, accessibility features, and offline assistance services.

## Features

### Smart Scheme Recommendation

* Machine learning-based eligibility prediction
* Personalized scheme suggestions
* Confidence-based recommendations

### Scheme Discovery

* State and central scheme exploration
* Voice search support
* Text-to-speech accessibility

### Assistance Services

* CSC center locator
* NGO assistance directory
* Automated government notice scraping

### Grievance Management

* Submit grievances
* Track complaint status
* Admin resolution workflow

## Technology Stack

### Frontend

* React.js
* Tailwind CSS

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Machine Learning

* Flask
* Scikit-learn
* Random Forest

## How to Run

1. Clone the repository.
2. Install frontend and backend dependencies.
3. Configure MongoDB connection and environment variables.
4. Start the backend server.
5. Start the frontend application.
6. Run the Flask recommendation service.
